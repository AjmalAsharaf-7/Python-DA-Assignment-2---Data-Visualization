# Python-DA-Assignment-2---Data-Visualization
Data visualization project using Python, Pandas, Matplotlib, and Seaborn to analyze the Taxis dataset, handle missing values, and create charts to explore taxi fares, trip distances, payment methods, and pickup locations.
# Python DA Assignment 2 – Data Visualization

## 📌 Project Overview

This project focuses on data visualization using Python libraries such as Pandas, Matplotlib, and Seaborn. The Seaborn Taxis dataset is used to explore data, handle missing values, and create different types of visualizations.

## 🎯 Objectives

* Load and explore the Taxis dataset.
* Identify and handle missing values.
* Create visualizations using Matplotlib and Pandas.
* Analyze taxi fares, trip distances, payment methods, and pickup boroughs.
* Understand relationships between numerical variables using Seaborn.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## 📊 Tasks Completed

### 1. Data Loading and Cleaning

* Loaded the Taxis dataset using Seaborn.
* Checked for missing values.
* Handled missing numerical values using the median.
* Handled missing categorical values using the mode.

### 2. Visualizations Using Matplotlib and Pandas

* Line Chart – Fare over time.
* Bar Chart – Total fare by pickup borough.
* Pie Chart – Trip distribution by payment method.
* Histogram – Distribution of trip distances.
* Box Plot – Tip distribution by pickup borough.

### 3. Visualizations Using Seaborn

* Count Plot – Number of trips by pickup borough.
* Scatter Plot – Relationship between distance and fare.
* Heatmap – Correlation between numerical variables.
* Pair Plot – Relationships between distance, fare, tip, and total.
* Violin Plot – Fare distribution by payment method.

## 📚 Key Learnings

* Data cleaning and missing value handling.
* Data exploration using Pandas.
* Creating charts using Matplotlib and Seaborn.
* Understanding data distributions and correlations.
* Visualizing relationships between variables.
